## 📌 Executive Overview

Modern software engineering focuses predominantly on runtime performance and feature velocity, largely overlooking the physical electricity consumption and carbon emissions generated by code execution.

**EcoCode** is an integrated software sustainability platform engineered to measure, quantify, and automatically optimize software resource footprints. By pairing a **hardware-agnostic proxy profiler**, an **AST/regex static Green-Code advisor**, a **live A/B algorithm performance scoreboard**, and an **automated CI/CD regression gatekeeper**, EcoCode empowers developers and DevOps teams to visualize and slash energy waste instantly.

---

## 🚀 Key Innovations & Features

### 1. ⚡ Hardware-Agnostic Proxy Profiler
- Quantifies physical execution duration ($T$ in seconds) via sandboxed Python execution.
- Maps compute duration to a simulated cloud server CPU workload profile (~100W / 0.1 kW load):
  $$\text{Energy (kWh)} = \left(\frac{T}{3600}\right) \times 0.1\text{ kW}$$
  $$\text{Carbon Footprint (kgCO}_2\text{e)} = \text{Energy (kWh)} \times \text{Grid Intensity Factor (0.8)}$$
  $$\text{Financial Cost (₹)} = \text{Energy (kWh)} \times \text{Commercial Rate (₹8/kWh)}$$
- Projects real-world equivalents scaled to 1,000,000 API calls (Smartphone full charges, 10W LED bulb burn hours, gasoline car km).

### 2. 🔍 Proactive Green-Code Advisor (Static Heuristics)
- Scans source code using Abstract Syntax Trees (AST) and regex heuristics to flag:
  - **$O(N^2)$ Nested Loops**: Suggests hash sets, maps, or vectorization.
  - **Inefficient Pandas Looping (`.iterrows()`)**: Recommends `.itertuples()` or column vectorization.
  - **Unclosed Descriptors (`open()` without `with`)**: Prevents kernel handle and memory leaks.
  - **String Concatenation in Loops (`+=`)**: Recommends `str.join()`.
  - **Linear Search in Iterations (`x in list`)**: Recommends $O(1)$ set conversions.
- Generates an **EcoCode Grade (A+ to F)** and a 0–100 Sustainability Score with side-by-side refactoring snippets.

### 3. ⚖️ Live A/B Algorithm Scoreboard & Visualizer
- Compares baseline code against green-optimized alternatives addressing the same business logic.
- Preloaded scenarios:
  - **Lookup Challenge**: Linear Search in List $O(N)$ vs Hash Set $O(1)$.
  - **Matrix Computation**: Nested loop iterations vs Flattened generator comprehension.
  - **String Builder**: Repeated buffer reallocation (`+=`) vs Single-pass `join()`.
  - **Data Processing**: Iterative dictionary record parsing vs Vectorized factors.
- Renders grouped Plotly charts comparing Execution Time (ms), Carbon (mg CO₂e), and Energy (μWh).

### 4. 🛡️ CI/CD Pipeline Energy Guard (Regression Gatekeeper)
- Automated GitHub Actions simulation to stop carbon regression before production merges.
- Compares PR metrics against `baseline.json`.
- **Enforcement Rule**: If energy consumption increases by **> 10%**, the gate fails, blocks the merge, and generates a formatted Markdown PR comment with remediation advice.

### 5. 💬 AI Green Consultant Chatbot
- Contextual green software engineering advisor.
- Powered by a comprehensive built-in GreenOps knowledge base + optional Google Gemini API support for real-time generative query resolution.

## 🛠️ Quick Start Guide

### Prerequisites
- Python 3.9 or higher

### Installation
```bash
# Clone the repository
git clone https://github.com/your-repo/ecocode.git
cd "sustainable project"

# Install dependencies
pip install -r requirements.txt
```

### Running Automated Tests
```bash
python tests/test_ecocode.py
```

### Launching the Dashboard
```bash
streamlit run app.py
```
The application will launch in your browser at `http://localhost:8501`.
